# Abhijeet Yadav — Portfolio Website

Interactive personal portfolio built with React, Vite, Tailwind CSS, and Three.js.

> Repository created for the source-only safe-fix version of the existing portfolio. Full application source needs to be uploaded before deploying.

## Development

Requirements: Node.js 22.12+ (or compatible Vite 8 runtime).

```bash
npm ci
npm run dev
npm run build
```

## Cloudflare Pages

- Framework: Vite / React
- Production branch: `main`
- Build command: `npm run build`
- Output directory: `dist`
- Root directory: `/`
